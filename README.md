# 💳 Digital Banking Dashboard

A modern and responsive **Digital Banking Dashboard** built using HTML, CSS, and JavaScript.

This project simulates a simple banking application where users can manage their balance, deposit money, withdraw money, transfer money, and view transactions dynamically.
## 🌐 Live Demo

👉 https://aritraghorai053.github.io/Digital-Banking-Dashboard/

## 🚀 Features

- 📊 **Dashboard Overview**https://aritraghorai053.github.io/Digital-Banking-Dashboard/
  - Total balance
  - Total income
  - Total expenses
  - Total savings

- 💰 **Deposit Money**
  - Add money to the account
  - Automatically update balance and income
  - Add a new transaction

- 💸 **Withdraw Money**
  - Withdraw money from the account
  - Check for insufficient balance
  - Automatically update balance and expenses
  - Add a withdrawal transaction

- 💳 **Transfer Money**
  - Enter recipient name
  - Enter account number
  - Transfer money
  - Validate balance and input
  - Add transfer to transactions

- 🧾 **Dynamic Transactions**
  - Transactions are generated using JavaScript
  - Income and expense amounts have different signs
  - Category-based icons
  - New transactions appear at the top

- 🕒 **Real Date & Time**
  - New transactions automatically use the current date and time

- 📱 **Responsive UI**
  - Clean banking dashboard interface
  - Responsive design for different screen sizes

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. For the best development experience, use the **Live Server** extension in VS Code.
